# Kwil logo

Original artwork made for Kwil (2026-10-23, KW-38): a pen nib in flight writing a line, in cold ice blue.

| File | Use |
|---|---|
| `kwil-icon.svg` | App icon master, 64 px and up |
| `kwil-icon-small.svg` | App icon at 16–48 px (simplified: bigger nib, solid trails, no glow) |
| `kwil-mark.svg` | Mark without tile, for dark backgrounds |
| `kwil-mono.svg` | One colour (`currentColor`), for tray icons, favicons and print |
| `kwil-wordmark.svg` | Mark plus "kwil" lettering (strokes, no font needed) |

Colours: navy `#080d18`–`#16243d`, ice `#f2fbff` → `#8fe3ff` → `#2f86ff`, accent `#5cc8ff`.
