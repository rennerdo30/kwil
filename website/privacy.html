Privacy

This website

This site sets no cookies, uses no analytics and loads nothing from other sites except one request: your browser asks the public GitHub API for the list of Kwil releases, so the download links point at the newest version. GitHub receives that request like any other visit to GitHub. The site itself is hosted on GitHub Pages, which keeps its own server logs; see the GitHub privacy statement.

The Kwil app

Kwil has no account and no telemetry. The only network request it makes is the update check against GitHub's release list, plus the download of an update when one is installed. You can turn the check off with check = false in the [update] section of the settings file. Markdown previews show local images only and never fetch from the internet.
