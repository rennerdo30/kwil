# Markdown visual checks

Open `showcase.md` and switch Text → Preview → Split. Resize, zoom the editor, open each menu over the view, edit a paragraph, scroll each pane, switch tabs, and return to Text. The preview must use the complete current snapshot, preserve the text pane, keep menus above content, and never edit behind a Preview-only pane.

The fixture covers CommonMark/GFM inline styles, global references, lists, tasks, quotes, tables, local images, code fences, missing images and Unicode. `colors.png` is an original 320×100 test image. No network images are loaded. Mermaid examples exercise the bounded native flowchart/sequence subset; unsupported declarations retain the fenced source with an explanation. SVG/WebP, HTML execution and remote image requests are unavailable.
